# Low-Speed Wind Tunnel

## Project Goal

Design, build, characterize, and use a small low-speed wind tunnel to investigate how the angle of attack of an airfoil affects aerodynamic lift and observed airflow behavior.

## Status

Project started August 10, 2026.

Current phase: Research and preliminary design.

## Planned Systems

- Modular wind tunnel
- Flow straightening system
- Custom transparent test section
- Adjustable airfoil mount
- Airspeed measurement
- Lift-force measurement
- ESP32 data acquisition
- Python data analysis
- 3D-printed NACA airfoils

## Research Question

How does increasing the angle of attack of a small airfoil affect its measured lift and observed airflow behavior in a student-built low-speed wind tunnel?

## Documentation

This repository will contain CAD files, reference designs, electronics, firmware, experimental data, photographs, analysis, and final results.
