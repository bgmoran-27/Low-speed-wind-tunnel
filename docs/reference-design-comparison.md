# Wind Tunnel Reference Design Comparison

## Design A — Jerrod H Modular Wind Tunnel

### What I Like

- Modular construction
- Designed around a PC fan
- Replaceable sections
- Existing educational accessories

### Potential Problems

- Some components may be too large for my school's Prusa MK3S+
- Test section is not specifically designed for my lift measurement system
- I want greater access for instrumentation


## Design B — 3D Printer Gear Educational Wind Tunnel

### What I Like

- Smaller modules
- Easier to print
- Simple construction
- Useful reference geometry

### Potential Problems

- Designed as an educational demonstration
- Does not contain the force measurement system I want
- Test section would need substantial modification


## My Current Plan

Use existing designs to understand and reference the basic wind-tunnel geometry.

I plan to personally design or substantially modify:

- Test section
- Airfoil mounting system
- Angle-of-attack mechanism
- Load-cell force balance
- Airspeed sensor mount
- Electronics integration
- Data acquisition
- Test airfoils
