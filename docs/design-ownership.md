# Design Ownership and References

## Existing Designs Studied

This project studies existing educational and open-source wind-tunnel designs to understand common wind-tunnel architecture and construction methods.

All external designs used or modified will be credited.

## Components Expected to Use Existing Designs as References

- General tunnel architecture
- Contraction geometry
- Diffuser geometry
- Fan mounting concepts
- Flow-straightening concepts

## Components I Plan to Design

- Custom experimental test section
- Airfoil mounting system
- Adjustable angle-of-attack mechanism
- Airspeed sensor mounting system
- Load-cell force balance
- Electronics integration
- Data-acquisition system
- Airfoil test models
- Experimental procedures
- Data-analysis software

## Engineering Approach

Existing designs will be treated as reference designs rather than presented as original work. Changes and redesigns will be documented throughout the project.
